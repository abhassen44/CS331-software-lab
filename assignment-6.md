# Chosen UI: A mix of a Graphical User Interface (GUI) and a Conversational / Natural Language Interface

## Justification:

For an AI coding agent, using only one type of interface would not be enough. A hybrid UI is a better choice because the project has two different kinds of tasks.

The GUI is useful for all the setup and management work. For example, when a user needs to:
- Sign in
- Paste a GitHub repository link
- Upload files
- Manage indexed projects

A graphical interface is much easier and more familiar. Elements like buttons, text fields, dropdowns, and progress bars make these actions simple and clear. The file tree and code viewer also fit naturally into a GUI because users can directly click through folders and open source files just like in an IDE or file explorer.

The conversational interface is important because the main purpose of the project is to help users understand and interact with a large codebase through AI. Instead of manually searching through hundreds of files, the user can just ask questions in normal language, such as:
- "Where is the authentication logic?"
- "Explain this function."

This makes the system feel more intelligent and user-friendly. It reduces effort for the user and lets the AI handle the difficult part of searching, retrieving, and explaining the relevant code.

**Conclusion:** A combination of GUI for control and navigation and conversation for intelligent interaction is the most suitable choice for this project.
