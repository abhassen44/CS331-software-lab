**Chosen UI:** Hybrid of Graphical User Interface (GUI) and Conversational (Natural Language) Interface.

**Justification:**  
For a complex software engineering project like the AI "Coding Agent" (using RAG for codebase Q&A), a single UI paradigm falls short. A hybrid approach is ideal:

- **GUI / Direct Manipulation:**  
    - Handles structural tasks like user onboarding, GitHub repo URL input, and project management intuitively.  
    - Uses standard elements (text fields, dropdowns, buttons, progress bars) for seamless technical setup.  
    - Repository viewer employs a direct manipulation file tree for browsing directories, with syntax-highlighted code in a split-pane layout.
